# FullStack Academy

**آکادمی فول‌استک** یک اپلیکیشن دسکتاپ برای یادگیری ساختاریافته‌ی برنامه‌نویسی وب است؛ از اولین تگ HTML تا ساخت API، پایگاه داده، اپ موبایل و استقرار با Docker. مسیر یادگیری به زبان فارسی و بر پایه‌ی مستندات رسمی هر فناوری طراحی شده و هر قدم با یک تمرین واقعی و بازبینی کد هوش مصنوعی بسته می‌شود.

## برای چه کسانی است؟

برای کسانی که می‌خواهند از صفر شروع کنند و به سطح یک توسعه‌دهنده‌ی فول‌استک برسند؛ بدون پراکندگی بین ده‌ها ویدئو و مقاله. مسیر مشخص است، ترتیب درس‌ها اجباری است و برای هر تمرین بازخورد دقیق و شخصی دریافت می‌کنید.

## چه چیزی یاد می‌گیرید؟

- **مبانی فرانت‌اند:** HTML معنایی و دسترس‌پذیر، CSS مدرن، JavaScript (ES6+) و TypeScript
- **ابزارهای حرفه‌ای:** Git و جریان کاری Pull Request، مدیریت بسته با npm/pnpm/yarn و ساخت پروژه با Vite
- **توسعه‌ی وب پیشرفته:** React و Hooks، مدیریت State با Context/Zustand/Redux و Next.js با App Router
- **موبایل:** React Native و Expo، مسیریابی با Expo Router و دسترسی به APIهای بومی دستگاه
- **بک‌اند و داده:** Node.js، Express، NestJS، PostgreSQL با Prisma و GraphQL
- **DevOps و کیفیت:** Docker، امنیت وب بر اساس OWASP، تست واحد با Jest و تست End-to-End با Playwright

## چطور کار می‌کند؟

۱. هر درس یک متن فارسی فشرده با مثال‌های کد و لینک مستقیم به مستندات رسمی است.
۲. در پایان درس یک تمرین شغلی واقعی می‌گیرید؛ کد را در یک مخزن عمومی GitHub می‌گذارید و آدرس آن را به برنامه می‌دهید.
۳. برنامه کد شما را می‌خواند و با معیارهای همان تمرین مقایسه می‌کند؛ نتیجه به‌صورت فهرست معیارهای تأییدشده، ایرادها و پیشنهاد اصلاح نمایش داده می‌شود.
۴. اگر جایی ضعف داشته باشید، یک «مینی‌درس» کوتاه و اختصاصی برای همان مفهوم ساخته می‌شود.
۵. تا وقتی همه‌ی معیارهای تمرین تأیید نشوند، درس بعدی باز نمی‌شود. این یعنی مسیر بدون جا افتادن جلو نمی‌رود.

بازبینی با **کلید هوش مصنوعی خودتان** (Google Gemini، OpenAI یا Anthropic) انجام می‌شود؛ کلید فقط روی رایانه‌ی شما و به‌صورت رمزنگاری‌شده ذخیره می‌شود. پس از ذخیره‌ی کلید، فهرست مدل‌های در دسترس به‌صورت خودکار شناسایی و برای انتخاب نمایش داده می‌شود.

## نصب آسان

**ویندوز** (PowerShell):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/DashAkoul/fullstack-academy/main/scripts/install.ps1 | iex"
```

**macOS و لینوکس** (ترمینال):

```bash
curl -fsSL https://raw.githubusercontent.com/DashAkoul/fullstack-academy/main/scripts/install.sh | bash
```

یا فایل مناسب سیستم‌عامل خود را از [صفحه‌ی نسخه‌ها](https://github.com/DashAkoul/fullstack-academy/releases/latest) دانلود کنید:
نسخه‌ی نصبی یا پرتابل ویندوز، دیسک‌ایمیج مک و AppImage یا بسته‌ی deb برای لینوکس.

نسخه‌ی جدید را می‌توانید از داخل برنامه و از بخش **تنظیمات → به‌روزرسانی** بررسی کنید؛ اگر نسخه‌ی تازه‌تری منتشر شده باشد، لینک دانلود همان‌جا نمایش داده می‌شود.

## نکته‌های کاربردی

- پیشرفت شما کاملاً محلی و روی همان دستگاه ذخیره می‌شود؛ حساب کاربری یا سرور میانی وجود ندارد.
- برای بازبینی کد، مخزن باید **عمومی** باشد.
- بدون اتصال به اینترنت، متن درس‌ها و تمرین‌ها در دسترس است؛ فقط بازبینی کد به شبکه نیاز دارد.
- رابط برنامه از راست به چپ طراحی شده و در حالت تاریک و روشن کار می‌کند.
